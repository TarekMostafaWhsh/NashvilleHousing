# 🏠 Nashville Housing Data Cleaning Project

### 📋 Overview
The goal of this project is to clean and organize housing data using SQL to make it ready for analysis.

### 🔧 Tools Used
- SQL Server
- CTEs, Joins, Subqueries, Date conversion

### 📈 Key Steps
- Removed duplicates using `ROW_NUMBER()`
- Split address columns using `SUBSTRING()` and `CHARINDEX()`
- Converted date formats using `CONVERT()`
- Standardized data for further analysis
